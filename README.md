# DLP Playbooks

Vendor-neutral data loss prevention (DLP) triage playbooks, informed by hands-on DLP investigation work during a Microsoft Purview onboarding.

These playbooks describe **process and decision logic only**. They contain no employer policies, sensitive information types, thresholds, user data or screenshots.
